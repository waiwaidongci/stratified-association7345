# Initial schema
SQLAlchemy metadata.create_all initializes the six business tables (including sensitivity_runs) plus users and audit on first start. Unique keys: study.code, (stratum.study_id,stratum.code), count.stratum_id, run.name, sensitivity_run.name, note.title. Foreign keys form study→stratum→count, study→run→note, sensitivity_run→run and note→sensitivity_run (nullable). This is not a production schema migration mechanism; use a versioned migration tool before evolving persisted deployments.
